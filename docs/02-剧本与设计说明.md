# 《平行未来 2046 · 职业模拟器》设计与剧本说明

> 这份文档有三个用途：① 填《参赛作品信息表》时直接摘抄；② 做「创作过程材料」里的剧本大纲；③ 决赛答辩时的提词器。
> 版本：v2（六个职业 / 24 个结局）。四个新增职业的完整剧本见 `05-新增四个职业剧本-待审.md`。

---

## 一、一句话概念

**你选一个 2046 年的新职业，替它做三个决定，然后拿到一张属于你自己的「未来职业档案卡」。**

主题：当 AI 越来越擅长给出「最优解」，人还剩多少余地去做一个「不划算」的选择。

选题对应大赛第（五）项「未来实验室」——不是讲 AI 有多强，而是把 AI 放进具体职业的一线现场，让人在**两难**之间做取舍。

---

## 二、为什么这样设计（创意理念，可直接用于信息表）

市面上的 AI 互动作品，九成是「AI 生成一段文字/一张图给你看」。评委看三秒就知道这是**展示**，不是**作品**。

我们反过来做：**AI 在故事里是角色，在制作里是工具，在机制里是被质疑的对象。**

- 故事里，每个职业都有一个 AI 同事：乡村线的「阿久」、心理线的「心屿」、记忆线的「回声」、课堂线的「小满」、生物线的「白塔」、遗产线的「卷宗」。它们会算、会算错、会沉默，也会在档案卡背面留下一句不该留的话。
- 机制上，玩家的选择被记成两条轴，而**每条职业的轴都不一样**：秩序/人情、规程/在场、温柔/真实、成长/保护、规则/例外、权利/延续。**没有「正确答案」**——全选一侧会拿到漂亮的指标和一个空掉的东西。
- 结构上，6 个职业 × 3 个决定 × 2 个选项 = **24 条路径、24 个结局**。其中每职业都有一个「全选系统侧」的**反讽结局**：所有指标全绿，代价写在档案卡背面。

一句话给评委：**「我们不是让 AI 替人做决定，而是让人在 AI 给出最优解的时候，练习说『不』。」**

**结局判定**：每个职业按「第二轴（人情 / 在场 / 真实 / 成长 / 例外 / 延续）」计数 3 / 2 / 1 / 0 → 四个结局；6 个职业共 **24 个**。

| 职业 | 3 | 2 | 1 | 0（反讽结局） |
|---|---|---|---|---|
| 乡村 | 守灯人 | 第三条田埂 | 云端规划师 | **最优解** |
| 心理 | 天台的月亮 | 双师制 | 标准化流程 | **完美模型** |
| 记忆 | 不删的人 | 剪辑师 | 档案管理员 | **完美的一生** |
| 课堂 | 不考试的人 | 留白的老师 | 增长负责人 | **完美陪伴** |
| 生物 | 例外 | 名单上的人 | 白塔的规则 | **完美效率** |
| 遗产 | 立规者 | 判例法 | 流程负责人 | **永不落幕** |

最后那一列是隐藏结局，也是最扎心的六个：拿到它们需要**三次都选系统侧**，而 UI 会一路给正反馈（指标全绿、「+1」提示）——直到结局页才告诉你代价。这是整个作品的态度。

## 四、交互设计（评委最看重的部分）

| 设计 | 说明 |
|---|---|
| 六职业选卡 | 3×2 卡片，每张带该职业第一幕的场景缩略图（26s 缓慢漂移），一屏看完六个方向 |
| 打字机对话 | 文字逐字出现，点击任意处跳过，符合「有人在跟你说话」的体感 |
| HUD 双轴 | 右上角两条细进度条实时记录当前职业的两条轴（标签随职业变），玩家能看见自己正在变成谁 |
| 选择反馈 | 选项按下时背景闪光（冷蓝/暖橙）+ 轻微撞击，Toast 弹出「温柔 +1」，让判断有物理重量感 |
| 镜头运动 | 每幕背景用 JS `requestAnimationFrame` 做 36–46 秒的连续推/摇（六种运镜预设），静止图有电影感；选择瞬间定格，把注意力交还给文字 |
| 键盘操作 | `1` / `2` 直接选选项，`空格`/回车推进；手机端点按即可 |
| 解锁系统 | `localStorage` 记住已解锁结局（0/24），鼓励重玩另一条路 |
| 档案卡 | 结局页右侧是「未来职业档案卡」：姓名、职业、倾向、坐标、金句、编号；点「保存档案卡」用 canvas 导出 1080×1560 PNG，可直接发朋友圈 |
| 零依赖 | 单个 HTML 文件，不联网、不加载字体库，双击就能玩；部署到静态托管后微信里也能打开 |

**交互的「意义」**（答辩话术）：进度条不是装饰——它把「你在做价值判断」这件事**可视化**了。玩家第一次看到「人情 0」的时候，会不舒服，这个不舒服就是作品想传达的东西。

## 五、AI 到底用在哪（答辩核心，务必背下来）

分三层说，一层比一层深：

1. **素材层（可见）**：24 张场景图全部由平台图像模型生成（豆包 Seedream 5 Pro / GPT Image 2），风格统一为「3D 动画电影质感 + 赛博东方」；背景音乐由 Suno 生成；部分台词由大模型辅助扩写后人工重写。
2. **流程层（可讲）**：我们把 AI 当「数字员工」——出图是执行，提示词是**导演指令**。24 张图对应 24 个情绪节拍，每张都规定了构图、色调、人物占比、留白位置（下半屏必须偏暗，因为对话框压在那里），不是「随便生成好看的图」。
3. **叙事层（最深）**：**这个作品的主题本身就是 AI**。六个 AI 同事都在算最优解，而玩家的每一个选择都是在回答「最优解是不是唯一解」。**AI 不只是工具，它是被讨论的对象。**

反过来说更清楚：如果把 AI 生成的图换成手绘图，这个作品依然成立，但会失去「未来感的具体质感」；如果把二十四个决定的价值观设计拿掉，这个作品就只剩一个图片浏览器。**骨架是我们写的，血肉是 AI 长的，但审美判断和价值观是人做的。**

## 六、技术规格

- 单文件 `index.html`，约 93KB，零第三方依赖，可离线运行
- 适配 1440×900 桌面与 390×844 手机（含 iOS 安全区）；≤1080px 选卡变两列，≤520px 变单列
- 不支持 WebGL / 老浏览器自动降级为渐变背景，不白屏
- 素材目录：`assets/scenes/v1~v4.jpg`、`m1~m4.jpg`、`y1~y4.jpg`、`c1~c4.jpg`、`b1~b4.jpg`、`l1~l4.jpg`、`assets/audio/bgm.mp3`
- 缺图自动降级为对应色调渐变，可以边出图边看效果

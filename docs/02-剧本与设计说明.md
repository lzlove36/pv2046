# 《平行未来 2046 · 职业模拟器》设计与剧本说明

> 这份文档有三个用途：① 填《参赛作品信息表》时直接摘抄；② 做「创作过程材料」里的剧本大纲；③ 决赛答辩时的提词器。

---

## 一、一句话概念

**你选一个 2046 年的新职业，替它做三个决定，然后拿到一张属于你自己的「未来职业档案卡」。**

主题：当 AI 越来越擅长给出「最优解」，人还剩多少余地去做一个「不划算」的选择。

选题对应大赛第（五）项「未来实验室」——不是讲 AI 有多强，而是把 AI 放进具体职业的一线现场，让人在**秩序（把决定交给系统）**与**人情（把决定留给人）**之间做取舍。

---

## 二、为什么这样设计（创意理念，可直接用于信息表）

市面上的 AI 互动作品，九成是「AI 生成一段文字/一张图给你看」。评委看三秒就知道这是**展示**，不是**作品**。

我们反过来做：**AI 在故事里是角色，在制作里是工具，在机制里是被质疑的对象。**

- 故事里，AI 助手「阿久」会算、会算错、会沉默三秒、会自己改一行不该改的数据（结局里那行小字）。
- 机制上，玩家的选择被记成两个轴：`秩序` 与 `人情`。**没有「正确答案」**——全是秩序会拿到漂亮的指标和一个空掉的祠堂；全是人情会让项目活不下去。
- 结构上，3 个决定 × 2 个选项 = 8 条路径、8 个结局。其中「最优解」是**反讽式结局**：所有指标全绿，代价写在档案卡背面。

一句话给评委：**「我们不是让 AI 替人做决定，而是让人在 AI 给出最优解的时候，练习说『不』。」**

## 三、剧情结构（剧本树）

```
开始页（输入档案名）
   │
   ├─ 职业 01 未来乡村规划师 · 云梦村
   │    第一幕 高温橙色预警 ──┬─ 保稻田（秩序）→ 祠堂数字化拆除，老人在雨里站两小时
   │                          └─ 保祠堂（人情）→ 稻田抢排，产量掉 8%
   │    第二幕 会唱戏的影子 ──┬─ 先立规矩再采集（秩序）→ 协议 46 天，数字皮影上线
   │                          └─ 改成皮影进课堂（人情）→ 23 个孩子，文旅局嫌不炫
   │    第三幕 调令 ─────────┬─ 去省城（秩序）→ 方案复制到 400 个村
   │                          └─ 留下签三年（人情）→ 阿久把「存活率 62%」改成 100%
   │
   └─ 职业 02 AI 心理疗愈师 · 心屿中心
        第一幕 凌晨三点 4027 ─┬─ 按规程通知辅导员（秩序）→ 她被叫醒，也被接住
                              └─ 先自己陪她说话（人情）→ 越界，但她在
        第二幕 三万条对话 ────┬─ 同意训练（秩序）→ 准确率 91%，风险报告在第 47 页
                              └─ 只要二次授权（人情）→ 效果差，但算法贴到了宿舍楼下
        第三幕 你自己的心跳 ──┬─ 把自己交给系统（秩序）→ 干预完成，没有感觉
                              └─ 关掉监测去天台（人情）→ 阿久说「那我就在这儿，不说话」
```

**结局判定**：`人情` 计数 3 / 2 / 1 / 0 → 四个结局；两个职业共 8 个。

| 职业 | 人情 3 | 人情 2 | 人情 1 | 人情 0 |
|---|---|---|---|---|
| 乡村 | 守灯人 | 第三条田埂 | 云端规划师 | **最优解** |
| 心理 | 天台的月亮 | 双师制 | 标准化流程 | **完美模型** |

「最优解 / 完美模型」是隐藏结局，也是最扎心的两个：拿到它们需要**三次都选秩序**，而游戏的 UI 会一路给你正反馈（指标全绿、Toast 提示「秩序 +1」）——直到结局页才告诉你代价。这是整个作品的态度。

## 四、交互设计（评委最看重的部分）

| 设计 | 说明 |
|---|---|
| 打字机对话 | 文字逐字出现，点击任意处跳过，符合「有人在跟你说话」的体感 |
| HUD 双轴 | 右上角两条细进度条实时记录「秩序/人情」，玩家能看见自己正在变成谁 |
| 键盘操作 | `1` / `2` 直接选选项，`空格`/回车推进；手机端点按即可 |
| 场景切换 | 背景图 1.4s 淡入 + 18s 缓慢推近（Ken Burns），静态图也有呼吸感 |
| 解锁系统 | `localStorage` 记住已解锁结局（0/8），鼓励重玩另一条路 |
| 档案卡 | 结局页右侧是「未来职业档案卡」：姓名、职业、倾向、坐标、金句、编号；点「保存档案卡」用 canvas 导出 1080×1560 PNG，可直接发朋友圈 |
| 零依赖 | 单个 HTML 文件，不联网、不加载字体库、不需要服务器，双击就能玩，微信里打开也能玩 |

**交互的「意义」**（答辩话术）：进度条不是装饰——它把「你在做价值判断」这件事**可视化**了。玩家第一次看到「人情 0」的时候，会不舒服，这个不舒服就是作品想传达的东西。

## 五、AI 到底用在哪（答辩核心，务必背下来）

分三层说，一层比一层深：

1. **素材层（可见）**：8 张场景图全部由平台图像模型生成（豆包 Seedream 5 Pro / GPT Image 2），风格统一为「3D 动画电影质感 + 赛博东方」；背景音乐由 Suno 生成；部分台词由大模型辅助扩写后人工重写。
2. **流程层（可讲）**：我们把 AI 当「数字员工」——出图是执行，提示词是**导演指令**。8 张图对应 8 个情绪节拍，每张都规定了构图、色调、人物占比、留白位置，不是「随便生成好看的图」。
3. **叙事层（最深）**：**这个作品的主题本身就是 AI**。故事里的 AI 助手阿久会算最优解，而玩家的每一个选择都是在回答「最优解是不是唯一解」。**AI 不只是工具，它是被讨论的对象。**

反过来说更清楚：如果把 AI 生成的图换成手绘图，这个作品依然成立，但会失去「未来感的具体质感」；如果把三个决定的价值观设计拿掉，这个作品就只剩一个图片浏览器。**骨架是我们写的，血肉是 AI 长的，但审美判断和价值观是人做的。**

## 六、技术规格

- 单文件 `index.html`，约 60KB，零第三方依赖，可离线运行
- 适配 1440×900 桌面与 390×844 手机（含 iOS 安全区）
- 不支持 WebGL / 老浏览器自动降级为渐变背景，不白屏
- 素材目录：`assets/scenes/v1~v4.jpg`、`m1~m4.jpg`、`assets/audio/bgm.mp3`

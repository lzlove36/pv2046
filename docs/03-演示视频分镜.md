# 演示视频分镜脚本（成片 ≤ 3 分钟，MP4）

> 评委看视频就两件事：**① 这真的是能玩的东西；② 选择真的会改变结果。**
> 所以整条片子必须有 2 次以上「点了不同按钮 → 画面/剧情明显变了」的完整镜头，不能剪。

## 录制前

- 分辨率 1920×1080，30fps，声音：后期配旁白（不用现场录，现场会录到键盘声）。
- 录屏工具：Win + G（Xbox Game Bar）够用；想要更干净用 OBS，只录「浏览器窗口」。
- **先把浏览器缩放调到 100%，隐藏书签栏（Ctrl+Shift+B），用 F11 全屏**，画面上只留游戏。
- 提前把 8 张图都放好、BGM 也放好，再开始录——**素材没齐之前不要录**，因为重录成本很高。
- 建议录两遍：第一遍走「全秩序」拿隐藏结局，第二遍走「全人情」拿另一个结局，剪辑时对比。

## 剪辑要点

- **不要加转场特效**（尤其不要花哨的推拉缩放）。大赛明确写过「仅加转场/缩放的静态作品不予接收」，你的素材是真实交互，越朴素越可信。
- 关键画面加**极简字幕**（左下角一行），字要大，评委可能在手机上看。
- 音量：旁白 -6dB，BGM -20dB，BGM 只在 0:00–0:35 和 2:40–3:00 出现，中间压低或静音，突出对话。
- 导出：H.264 / MP4 / 1080p / 码率 8–10 Mbps，控制在 150MB 以内（邮件附件友好）。

## 一定要避免

- ❌ 录屏时出现微信通知、桌面图标、其他浏览器标签
- ❌ 用鼠标乱晃、反复点同一个地方（显得没准备好）
- ❌ 用「AI 配音」念旁白（这一点大赛明确说过不足以为核心创作，但你已经有真实交互了，别在这里冒险——自己念，或者找同学念）
- ❌ 把视频做成「图片轮播 + 音乐」（这是红线）

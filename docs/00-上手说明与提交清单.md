## 三、怎么把游戏变成「可访问的链接」（三选一）

### 方案 A：直接发 HTML 文件（最稳，零成本）
邮件附件里放 `index.html` + `assets` 文件夹，评委解压后双击就能玩。缺点：手机上不好打开。

### 方案 B：GitHub Pages（推荐，5 分钟）
1. 建仓库 `pv2046`，把 `index.html` 和 `assets/` 传上去
2. Settings → Pages → Source 选 `main` / root → 保存
3. 得到 `https://<用户名>.github.io/pv2046/`，用草料二维码生成二维码
优点：永久、免费、手机能玩、答辩可以直接演示。

### 方案 C：Vercel（更快，可以拖拽上传）
vercel.com → Add New Project → 直接拖整个文件夹 → 得到 `xxx.vercel.app`。
优点：拖拽即部署；缺点：国内访问偶尔慢，**如果评委在国内，优先 B**。

> ⚠️ 部署前务必确认 `assets/scenes/` 里的图已经提交上去（大小写敏感，`v1.jpg` 不能写成 `V1.JPG`）。
